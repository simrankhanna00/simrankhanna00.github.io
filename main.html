Volume Control Using Hand Gestures

Project Overview: Gesture recognition helps computers to understand human body language. This helps to build a more potent link between humans and machines, rather than just the basic text user interfaces or graphical user interfaces (GUIs). In this project for gesture recognition, the human body’s motions are read by computer camera. Thecomputer then makes use of this data as input to handle applications. The objective of this project is to develop an interface which will capture human hand gesture dynamically and will control the volume level.

❮ ❯

Project Details

  • Used Mediapipe to detect and track hand landmarks from webcam input.
  • Measured distance between the thumb and index finger tips to dynamically map it to the system volume range.
  • Overlaid volume bar and percentage on webcam feed using OpenCV to reflect real-time changes.
  • Optimized the detection loop to minimize CPU usage and ensure low latency.

Technology Used: Python

Chat Application

Project Overview: The Chat Application is a real-time messaging system built using Java that allows users to communicate over a network. It can be used for one-on-one and group chats, making it suitable for personal or business communication. The application follows a client-server architecture, where a central server manages multiple client connections and routes messages between users.

❮ ❯

Project Details

  • Implemented using TCP sockets to facilitate real-time data exchange between clients via a server.
  • Built a simple and intuitive GUI using Swing (or JavaFX) for message input, display, and user interactions.
  • The server relays messages from one client to all other connected clients, creating a group chat effect..
  • Displays alerts when users join or leave the chat session.
  • Handled connection drops, unexpected exits, and reconnections gracefully.

Technology Used: Java
